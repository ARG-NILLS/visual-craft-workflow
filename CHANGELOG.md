## [1.2.0] - 2026-10-26

> Amplía el flujo con marketing de producto, rutas especializadas y validación basada en evidencia.

### 🧭 Flujo adaptable

- 🔀 Se sumaron rutas para marketing independiente y para trabajos que combinan diseño, experiencia y objetivos comerciales.
- 📚 Se separaron los procedimientos por tema para cargar solo la referencia pertinente y mantener livianos los ajustes puntuales.
- 🧩 Se reforzó la continuidad de marca, tecnologías, contexto y permisos entre etapas.

### 📣 Marketing de producto

- 🎯 Se incorporaron seis grupos: estrategia, contenido, adquisición, conversión y activación, retención y recomendación, operación y medición.
- 📊 Cada recomendación relaciona objetivo, acción, recursos, métrica y evidencia faltante.
- 🧪 Se aclaró que el impacto esperado es una hipótesis hasta medirlo y que no se envían campañas ni se gasta presupuesto sin autorización.

### ✅ Calidad y documentación

- 🔎 Se agregó una revisión técnica proporcional con estados cumple, falla, pendiente y no aplica, más prioridades por impacto.
- ♿ Se ampliaron las comprobaciones de interacción, formularios, adaptación, metadatos, recursos y movimiento reducido.
- 🧰 Se corrigieron afirmaciones generales sobre código de registros, dependencias y comandos de instalación.
- 📖 Se actualizó el mapa de archivos, las capacidades y los ejemplos del README.
- 🖼️ Se actualizó la portada, se sumó el diagrama nuevo y se conservó el banner anterior como respaldo.
- 🎞️ Se mantuvo el video como ejemplo animado del recorrido visual.

## [1.0.0] - 2026-10-23

> Primera versión estable y release inicial de Visual Craft Workflow.

### 🎨 Flujo visual y sistema

- 🧭 Se sumó un resumen visual basado en producto, tarea, plataforma, marca y restricciones.
- 🧩 Se incorporaron recomendaciones de sistemas visuales y tecnologías para proyectos nuevos o rediseños amplios; los ajustes puntuales conservan el sistema existente.
- 🔀 Se agregó enrutamiento selectivo para descubrir información, revisar usabilidad, tipografía, microinteracciones, conversión y rendimiento según la necesidad.
- 🗂️ Se añadieron puntos de control para trabajos extensos, reutilizando la documentación existente.
- ♿ Se reforzaron las revisiones con evidencia por tarea, impacto, prioridad y separación entre observaciones e inferencias.

### 🛠️ Criterios de calidad

- 🎛️ Se definieron responsabilidades para cada especialidad y un orden para resolver conflictos entre instrucciones, marca, comportamiento y accesibilidad.

- 🔒 Se aclaró que auditorías y planes son de solo lectura; correcciones y publicación requieren autorización.
